# Space Shooter

```
    ▲
   ▲▲▲     un space shooter clásico,
  ▲▲▲▲▲    hecho a mano en Python
```

Proyecto personal de **Pablo Arenas** ([@Areman-05](https://github.com/Areman-05)).  
Nave, asteroides, enemigos y power-ups — el objetivo es simple: sobrevive y sube tu puntuación.

---

## Qué es

Un arcade de disparos espaciales hecho con **Python** y **Pygame**.  
Controlas tu nave, esquivas peligros, recoges mejoras y te enfrentas a oleadas cada vez más duras.

### Incluye

- Movimiento libre y disparo
- Power-ups (escudo, misiles…)
- Oleadas y jefes
- Efectos de sonido
- Guardado de récords

---

## Controles

| Tecla | Acción        |
|-------|---------------|
| `W A S D` | Mover la nave |
| Disparo / misiles | Según lo configurado en partida |

---

## Cómo jugar

**Opción rápida (Windows):** doble clic en `ejecutar_juego.bat`.

**A mano:**

```bash
pip install -r requirements.txt
python "Juego Space Shooters/main.py"
```

Necesitas **Python 3** y **Pygame** (`pygame>=2.0.0`).
